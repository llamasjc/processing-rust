Write Processing sketches in Rust, inside the Processing IDE.

Install: download RustMode.zip, unzip it into the modes folder of your sketchbook (File > Preferences shows where that is), and restart Processing. If Rust isn't installed, Rust Mode offers to install it the first time you press Run.

What's in it:
- setup(), draw() and the event functions, with Processing's API: shapes, color, images, pixels, text and fonts, transforms, 3D, lights, shaders, PVector, Table, JSON, XML, the lists and dicts, and more.
- Two renderers, picked from the toolbar: the CPU renderer, which works everywhere, and libprocessing (Bevy and wgpu on your graphics card).
- All 161 of Processing's Basics and Topics examples, in Rust, under File > Examples.
- File > Export Application and File > Export as PDEZ.
- The engine comes precompiled, so the first Run is quick.

On Linux ARM, the precompiled libprocessing engine is a separate download (RustMode-libprocessing-linux-arm64.zip), because with it RustMode.zip would be bigger than GitHub allows. The first time you pick libprocessing there, Rust Mode offers to download it for you. You can also unzip it into your modes folder by hand.

Docs, reference and examples: https://processing-rust.github.io
