# RustMode 0.1.0

The first release of RustMode: write Processing sketches in Rust, inside the Processing IDE.
Press Run and the sketch compiles to a native program against a precompiled engine.

## Install

Download RustMode.zip, unzip it into the `modes` folder of your sketchbook (File > Preferences shows
where that is) and restart Processing. If Rust isn't installed, RustMode offers to install it the
first time you press Run.

## Processing's API, in Rust

- `setup()`, `draw()` and the event functions, the way Processing has them
- Shapes, color, images and pixels, text and fonts, transforms, 3D, lights and shaders
- PVector, Table, JSON, XML, and the lists and dicts (IntList, FloatDict and the rest)
- Video through ffmpeg (Movie and Capture); RustMode offers to install ffmpeg the first time a sketch needs it
- All 161 of Processing's Basics and Topics examples, in Rust, under File > Examples

## Two renderers

Pick one from the toolbar:

- **CPU**: draws in software and works everywhere. The default.
- **libprocessing** (experimental): Bevy and wgpu on your graphics card, with real 3D lights and shaders

The engine comes precompiled for Linux (x86_64 and ARM), macOS (Intel and Apple Silicon) and Windows,
for both renderers, so the first Run is quick.

## Export Application

- One program per platform: `<Sketch>.exe` on Windows with your icon built in, a `.app` on macOS,
  and on Linux a program or an AppImage
- With the CPU renderer, export for Windows, Linux and macOS from any of them (Install buttons in the
  dialog set up what another platform needs)
- File > Export as PDEZ

## Without the IDE

- `processing-rust-starter.zip`: a Cargo project ready for `cargo run`
- `processing-rust-crate.zip`: the engine as a crate for your own projects (the README has the
  `[patch]` line Bevy needs)

## Known gaps

- libprocessing exports are for the computer you're on; the CPU renderer exports for all of them
- Windows and macOS have had less testing than Linux

Docs, reference and examples: https://processing-rust.github.io
